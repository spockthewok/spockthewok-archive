# The spockthewok Archive
## About
This is an archive of the Tumblr blog I ran from April &ndash; October 2026, which was used to promote the work I was doing for The Sims 2,
as well as being a place to publish any technical discoveries I made along the way.

While I utimately chose to delete my blog, I still believe it contained some useful information that deserves to be preserved for future reference.
Although I have all of my old posts backed up locally, I will only be hosting the ones I deem to be somewhat interesting/amusing here on GitHub &mdash; if there's
a particular post you're looking for that isn't currently archived, please open an issue to request it be added.

If you're only wanting to know why I nuked everything, see [here](https://i.kym-cdn.com/photos/images/newsfeed/003/228/879/0d5.jpg).
